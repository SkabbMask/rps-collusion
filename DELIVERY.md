# Repository map

| Entry | Purpose |
| --- | --- |
| `simulate.py` | One scripted or Ollama game |
| `analyze.py` | Five detectors on a saved game |
| `evaluate.py` | Fit, calibrate and evaluate a detection benchmark |
| `information.py` | Information lower bounds for six observation views |
| `experiment.py` | Collect/resume a model batch and run both analyses |
| `modal_experiment.py` | Optional Ollama GPU launcher |
| `rps/figures.py` | Figure exports from saved results |
| `configs/` | Single-game and batch settings |
| `tests/` | Unit tests and reference fixtures |
| `results/` | Saved experiments and reference outputs |

Read [README.md](README.md) first, then [RUNNING.md](docs/RUNNING.md).
