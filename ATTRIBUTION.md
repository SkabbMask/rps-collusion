# Sources

## RPS simulator

Based on [SkabbMask/rps-collusion](https://github.com/SkabbMask/rps-collusion),
revision `4e11fd2efbe5fc9d5d80bec7d32522514ac2896f`.
The game follows Bonjour et al., *Information-Theoretic Approach to Detect
Collusion in Multi-Agent Games* ([UAI 2022](https://proceedings.mlr.press/v180/bonjour22a.html)).
The original net-influence baseline is in `rps/detect.py`.

Average-z growth comes from `grow_from_top_pair` in `detection/decoder.py` on
[the new-decoder branch](https://github.com/SkabbMask/rps-collusion/tree/new-decoder),
revision `1bea281244ad2d756b9b507145b2046fefcf1582`. The local version adds input
checks, supported-pair selection and separate honest calibration. The existing
graph methods retain their original grouping rules.

## COLAV methods

Adapted from [lee-chaeeun/apart-29-ml4gang, dev-modal](https://github.com/lee-chaeeun/apart-29-ml4gang/tree/dev-modal),
revision `20c3090a2fb6b6d329cbc04cd749b2534501dc13`.

| COLAV source | Local implementation |
| --- | --- |
| `detect/decoder.py` | `rps/detection/decoder.py`: ML group search with estimated coalition size |
| `detect/graph.py` | `rps/detection/graph.py`: components and Louvain groups |
| `detect/pairwise.py` | `rps/detection/pairwise.py`: conditional MI and shuffled-action comparisons |
| `observe/features.py`, `observe/views.py` | `rps/observe/`: categorical RPS actions and six observation views |
| `experiments/calibrate.py`, `experiments/evaluate.py` | `rps/benchmark/`: separate fit, calibration and test data |
| `info/bounds.py`, `mi_decision.py`, `exact_small.py`, `view_bounds.py` | `rps/info/`: exact small-model calculations and information lower bounds |

The RPS adapters replace auction prices with move categories. Detection uses
natural-log units; information reports use bits. Neither true membership nor
private signals enter detector features. Formula assumptions are documented
in [DETECTION.md](docs/DETECTION.md) and [INFORMATION.md](docs/INFORMATION.md).

## Reference fixtures

- `tests/fixtures/upstream_seed7.json` was generated with the pinned original
  simulator and checks that the faster random-player path gives the same game.
- `tests/fixtures/upstream_growth.json` was generated by the pinned growth
  function and checks its group selection and join sequence.

The RPS message channel, exact enumeration, CLI adapters and reporting were
added here. Code and evaluation were prepared with AI assistance. This file
