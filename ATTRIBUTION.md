# Source lineage and adaptation

Target repository, used as the base of branch `feat/rps-colav-detection`:

- [SkabbMask/rps-collusion](https://github.com/SkabbMask/rps-collusion)
- Pinned revision: `4e11fd2efbe5fc9d5d80bec7d32522514ac2896f`.
- Existing `rps/game.py`, `rps/players.py`, `rps/ollama.py`, `rps/detect.py`, the game configuration
  and the original paper PDF are retained. `simulate.py` adds a sequential fast path for local
  RandomPlayer calls and optional invocation of the added detectors. LLM calls remain concurrent.

Detection-method source:

- [lee-chaeeun/apart-29-ml4gang, dev-modal](https://github.com/lee-chaeeun/apart-29-ml4gang/tree/dev-modal)
- Pinned revision: `20c3090a2fb6b6d329cbc04cd749b2534501dc13`.

| Original | Adaptation | Preserved method / deliberate change |
| --- | --- | --- |
| `colav/colav/detect/decoder.py` | `rps/detection/decoder.py` | Subset-sum Gaussian working likelihood, plug-in mu, unknown-k combinatorial penalty, exact/greedy search. Adds validation, bounded cached subsets, finite evidence, and fixes greedy initialization for all-negative edges. Only deployable plug-in mode is used; no true coalition size or oracle mean is supplied. |
| `colav/colav/detect/graph.py` | `rps/detection/graph.py` | Thresholded pair graph, connected components, Louvain, internal z-sum score. Both extractors return all accepted groups and use separate max-group calibration cutoffs. |
| `colav/colav/observe/features.py` | `rps/observe/features.py` | Observation/validity-mask architecture. Replaces auction-price differences with three categorical actions and arbitrary-cardinality public states. |
| `colav/colav/observe/views.py` | `rps/observe/views.py` | Six RPS-adapted views; removes price/valuation fields, separates evaluator-only maps, and uses only explicitly recorded public messages for full/metadata. |
| `colav/colav/detect/pairwise.py` | `rps/detection/pairwise.py` | Conditional MI, state-stratified permutation null, z scores, support checks. Uses nats consistently with the RPS baseline and computes per-pair cell support dynamically. |
| `colav/colav/experiments/calibrate.py` and `evaluate.py` | `rps/detection/pipeline.py`, `rps/benchmark/` | Honest null calibration, conservative order statistics, frozen testing, recovery metrics. Splits graph edge fitting from graph-score calibration into independent datasets. |

The original net-influence implementation follows the RPS repository's interpretation of
Bonjour et al., *Information-Theoretic Approach to Detect Collusion in Multi-Agent Games*, UAI 2022.
The original source is preserved as `rps/detect.py`; the added detector results do not replace it.

The six-view information extension additionally follows `colav/colav/info/bounds.py`,
`mi_decision.py`, `exact_small.py` and `view_bounds.py` at the source revision above.
The balanced-prior decision MI identity, exact-TV relations and conservative binomial
confidence construction are adapted in `rps/info/`. RPS-specific exact enumeration,
label-free feature maps, public-message logging and the evaluation/report CLI are new.
See `docs/INFORMATION.md` for assumptions and interpretation.

New code in this branch includes the RPS adapters, detector API, JSONL importer, streaming
benchmark, stress generators, reports, plots, provenance checks and regression tests.
The implementation and evaluation were prepared with AI assistance. No license grant is added
to upstream material by this attribution file; retain the original repositories' notices and terms.

`tests/fixtures/upstream_seed7.json` was generated by executing the pinned target `simulate.py`
with its original threaded random path. It verifies the new fast path preserves seeded outputs.
