# Saved experiments

Start with [the results guide](../docs/RESULTS.md) for run identities,
interpretation and replication checks. The main scripted reference is
[full-detection-growth/report.md](full-detection-growth/report.md).

Saved reports are historical records. Their numerical results and calibration
files are not rewritten when documentation changes. In particular, old
information reports may include the exact toy diagnostic, which was excluded
from the paper and is no longer generated by default.

Keep new experiments in separate directories. Incomplete attempts and local
progress files are not paper results.
